# Uday Chahal — Portfolio

**Live:** https://uday2611.github.io

Personal portfolio of Uday Chahal — B.Tech CSE (Data Science) at SRM IST, AWS & Oracle certified, building Generative AI, ML and data analytics projects.

## Built with
- HTML, CSS, JavaScript (no build step)
- [Three.js](https://threejs.org/) — 3D character and interactive tech-stack spheres
- [GSAP](https://gsap.com/) + ScrollTrigger — loader, text and scroll animations

## Editing content
All text, projects, certifications, skills and links live in [`data.js`](data.js).
Project images are in [`images/`](images/).
